# Getting people to love Husky Eye View: adoption kit

Seven steps, agreed with the project owner on 2026-10-18. This folder holds
what can be written or built in the repository; the rest needs a person.

| # | Step | Where it stands |
| --- | --- | --- |
| 1 | One main user and one main moment: a researcher's own data on the map in under five minutes | **In the app.** The first-run card leads with YOUR DATA, MAPPED (Merge & Export) and THEN AND NOW (the Time Lens swipe); Data Layers has MY FILES, whose Analyze button hands a file to Merge & Export. |
| 2 | A first try with no setup | **Assessed:** [hosted-demo.md](hosted-demo.md). Husky Merge already runs on the web with no setup; the full app needs a server for its live feeds and statistics. |
| 3 | Research in front | **In the app.** The tune button (MENUS ON SCREEN) hides menus a session does not need, with Research, Teach, Live world and Everything workspaces. |
| 4 | Citable and trustworthy | **Done:** [CITATION.cff](../../CITATION.cff), [METHODS.md](../METHODS.md) and a Zenodo DOI, [10.5281/zenodo.23582397](https://doi.org/10.5281/zenodo.23582397) (all versions). |
| 5 | Teaching | **Written:** three labs in [labs/](labs/). |
| 6 | Watch five real people use it | **Written:** [usability/protocol.md](usability/protocol.md). **Needs the owner:** recruit and run the sessions. |
| 7 | Show it where the audience is | **Written:** [demo/demo-kit.md](demo/demo-kit.md). |

## What only the owner can do

- **DOI.** Sign in to [Zenodo](https://zenodo.org) with GitHub, switch on the
  `nu-stats/husky-eye-view` repository under *GitHub*, then publish a GitHub
  release. Zenodo archives that release and mints a DOI. Add the DOI to
  `CITATION.cff` (`doi:`) and to the README badge. (Authors confirmed by the owner, 2026-10-22.)
- **Usability sessions.** Recruit five people from the main audience (graduate
  students and instructors in the social sciences and public health). Check
  with Northeastern's IRB whether the sessions count as human-subjects
  research; as product feedback with no research publication they usually
  do not, but the IRB decides.
- **Conference slots.** Submissions (ASA, PAA, AAG, or a methods workshop) go
  in under the owner's name.
