-------------------------------------------------------------------------------
STEP 31: Switching from Google 3D to Bing, Esri or OSM gave "Request has failed: 401"
-------------------------------------------------------------------------------
Cause:    The Cesium ion token was rejected by Cesium's servers (revoked or deleted on the
          ion account). Bing comes through ion, and Esri/OSM loaded their terrain through
          ion whenever a token was set, so all three failed.
Fix for the user (any time this happens):
          1. https://ion.cesium.com/tokens -> create a new token -> copy it.
          2. In the app: POWER UP -> CESIUM ION -> paste it.
          3. Stop and start the app in Pinokio, reload the page.
Code changes, so the app explains itself instead of just switching views:
  - Esri and OSM fall back to free terrain when ion refuses, and a notice says so, with
    the fix.
  - Bing shows "Cesium ion rejected the token (HTTP 401). Fix: ... Showing Google 3D
    instead."
  - Any map that falls back to another says which one it is showing.
  - Notices with a fix stay on screen up to 10 seconds (they used to vanish after 2).
Code:     src/maps/defaultSources.js, controller.js, imagery.js, src/ui/shellFeedback.js.
